# Netflix Watch History Analyzer

A simple beginner Python project that reads a Netflix watch-history CSV file and calculates:
- Total watching time
- Number of watch records
- Most-watched genre
- Most-watched title
- A basic genre bar chart

## Files
- `netflix_project.py` — Python code
- `netflix_watch_history.csv` — sample data

## How to run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib`
3. Keep both files in the same folder.
4. Run:
   `python netflix_project.py`

You can also open the code in Jupyter Notebook and run it cell by cell.

The included CSV is sample data for learning. Replace it with your own exported watch-history data if you have one.
